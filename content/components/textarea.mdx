## Usage

```tsx

```

```tsx
<Textarea aria-label="Message" placeholder="Tell us what happened…" />
```

## API Reference

| Prop          | Type                        | Default     |
| ------------- | --------------------------- | ----------- |
| `controlSize` | `"sm" \| "default" \| "lg"` | `"default"` |

`controlSize` sets the padding, text size and line height. The box grows with its content through `field-sizing: content`. Add `field-sizing-fixed` and a `rows` value to keep a fixed height.

All other props pass through to the native `<textarea>` element.
