## Installation

```bash
bunx shadcn@latest add davidodunjo/gantry/input-otp
```

## Usage

```tsx
import {
  InputOTP,
  InputOTPGroup,
  InputOTPSeparator,
  InputOTPSlot,
} from "@/components/ui/input-otp"
```

```tsx
<InputOTP maxLength={4} aria-label="Four digit code">
  <InputOTPGroup>
    <InputOTPSlot index={0} />
    <InputOTPSlot index={1} />
    <InputOTPSlot index={2} />
    <InputOTPSlot index={3} />
  </InputOTPGroup>
</InputOTP>
```

## API Reference

### InputOTP

| Prop                 | Type                                              | Default |
| -------------------- | ------------------------------------------------- | ------- |
| `controlSize`        | `"xxxs" \| "xxs" \| "xs" \| "sm" \| "md" \| "lg"` | `"md"`  |
| `containerClassName` | `string`                                          |         |

`controlSize` sets the box size, text size and corner radius for every slot. `containerClassName` styles the wrapper around the boxes, while `className` styles the hidden input. `aria-invalid` and `disabled` on the input are picked up by every slot.

All other props, including `maxLength`, `pattern`, `value`, `defaultValue`, `onChange` and `pasteTransformer`, pass through to [input-otp](https://github.com/guilhermerodz/input-otp).

### InputOTPGroup

A flex row that holds a set of slots. It takes the props of a `div`.

### InputOTPSlot

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `index` | `number` | none    |

`index` is the position of the box in the code and is required. The remaining props pass through to a `div`.

### InputOTPSeparator

A dash between two groups. It takes the props of a `div`.
