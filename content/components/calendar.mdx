## Usage

One date for a consultation slot. Today and every day before it are disabled, so the earliest pick is tomorrow.

```tsx
import { Calendar } from "@/components/ui/calendar"
```

```tsx
<Calendar mode="single" selected={date} onSelect={setDate} />
```

## API Reference

| Prop              | Type                                                             | Default   |
| ----------------- | ---------------------------------------------------------------- | --------- |
| `showOutsideDays` | `boolean`                                                        | `true`    |
| `captionLayout`   | `"label" \| "dropdown" \| "dropdown-months" \| "dropdown-years"` | `"label"` |
| `buttonVariant`   | Any [Button](/components/button) variant                         | `"ghost"` |

`buttonVariant` styles the previous and next month buttons. The calendar picks up the current right-to-left direction and flips its arrows. All other props, including `mode`, `selected`, `onSelect`, `disabled`, `numberOfMonths`, `defaultMonth`, `startMonth` and `endMonth`, pass through to [React Day Picker](https://daypicker.dev/api/interfaces/PropsBase).

`CalendarDayButton` is the button drawn for each day. It is exported for when you need to replace it through the `components` prop.
