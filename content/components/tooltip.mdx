## Installation

```bash
bunx shadcn@latest add @gantry/tooltip
```

## Usage

```tsx
import {
  Tooltip,
  TooltipContent,
  TooltipProvider,
  TooltipTrigger,
} from "@/components/ui/tooltip"
```

```tsx
<TooltipProvider>
  <Tooltip>
    <TooltipTrigger render={<Button variant="outline" />}>
      Hover or focus
    </TooltipTrigger>
    <TooltipContent>Save your changes</TooltipContent>
  </Tooltip>
</TooltipProvider>
```

## Basic

A short label that appears on hover or keyboard focus of its trigger, and disappears the moment focus or the pointer leaves. Shown open here so the label is visible without hovering.

## API Reference

### TooltipProvider

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `delay` | `number` | `300`   |

`delay` is how many milliseconds the pointer must rest on a trigger before its tooltip opens. Wrap the tooltips that should share this delay in one provider. All other props pass through to [Base UI's Tooltip Provider](https://base-ui.com/react/components/tooltip).

### TooltipContent

| Prop          | Type                                     | Default    |
| ------------- | ---------------------------------------- | ---------- |
| `title`       | `ReactNode`                              |            |
| `description` | `ReactNode`                              |            |
| `arrow`       | `boolean`                                | `false`    |
| `side`        | `"top" \| "right" \| "bottom" \| "left"` | `"top"`    |
| `sideOffset`  | `number`                                 | `6`        |
| `align`       | `"start" \| "center" \| "end"`           | `"center"` |
| `alignOffset` | `number`                                 | `0`        |

`title` takes the place of `children` as the bold first line. `description` adds a lighter second line and gives the tooltip more vertical padding. `side`, `sideOffset`, `align` and `alignOffset` position the tooltip against its trigger. All other props pass through to [Base UI's Tooltip Popup](https://base-ui.com/react/components/tooltip).

`Tooltip` and `TooltipTrigger` pass all props through to [Base UI's Tooltip](https://base-ui.com/react/components/tooltip).
