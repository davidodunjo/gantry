```bash
bunx shadcn@latest add davidodunjo/gantry/tags
```

## Usage

```tsx
import { Tag, TagGroup } from "@/components/ui/tags"
```

```tsx
<TagGroup label="Topics" selectionMode="multiple">
  <Tag id="design">Design</Tag>
  <Tag id="engineering">Engineering</Tag>
</TagGroup>
```

A tag on its own is a static chip. Put tags in a `TagGroup` with a `selectionMode` to make them selectable, or give a tag `onRemove` to add a close control.

## API Reference

### TagGroup

| Prop                  | Type                               | Default  |
| --------------------- | ---------------------------------- | -------- |
| `label`               | `string`                           | required |
| `size`                | `"sm" \| "md" \| "lg"`             | `"sm"`   |
| `selectionMode`       | `"none" \| "single" \| "multiple"` | `"none"` |
| `selectedIds`         | `string[]`                         |          |
| `defaultSelectedIds`  | `string[]`                         | `[]`     |
| `onSelectedIdsChange` | `(ids: string[]) => void`          |          |

`label` is read out by screen readers as the group's legend. Pass `selectedIds` to control the selection, or `defaultSelectedIds` to let the group keep it. Tags inherit `size` and `selectionMode` from the group. All other props pass through to the `fieldset`.

### Tag

| Prop            | Type                               | Default                         |
| --------------- | ---------------------------------- | ------------------------------- |
| `id`            | `string`                           | required                        |
| `size`          | `"sm" \| "md" \| "lg"`             | the group's size, else `"sm"`   |
| `selectionMode` | `"none" \| "single" \| "multiple"` | the group's mode, else `"none"` |
| `selected`      | `boolean`                          | from the group                  |
| `onSelect`      | `(id: string) => void`             | the group's handler             |
| `onRemove`      | `(id: string) => void`             |                                 |
| `disabled`      | `boolean`                          | `false`                         |
| `dot`           | `boolean`                          | `false`                         |
| `dotClassName`  | `string`                           |                                 |
| `count`         | `number`                           |                                 |
| `avatar`        | `TagAvatarProps`                   |                                 |

`onRemove` adds a close control that also responds to Backspace and Delete. `avatar` takes the props of an `img`, plus `fallback` for what shows when there is no `src` or it fails to load. All other props pass through to the wrapping `div`.

### TagAvatar

A small round image on its own. It takes the props of an `img`, plus `fallback`, which defaults to a person icon.
