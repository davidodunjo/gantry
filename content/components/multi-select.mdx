## Installation

```bash
bunx shadcn@latest add davidodunjo/gantry/multi-select
```

## Usage

```tsx
import {
  MultiSelect,
  type MultiSelectOption,
} from "@/components/ui/multi-select"
```

```tsx
<MultiSelect
  label="Integrations"
  options={integrations}
  defaultValue={["slack"]}
/>
```

Several answers at once. Every row is a tick box, the trigger counts what is on rather than naming it, and the popup stays open so you can keep going.

## API Reference

### MultiSelect

| Prop             | Type                        | Default            |
| ---------------- | --------------------------- | ------------------ |
| `options`        | `MultiSelectOption[]`       | required           |
| `label`          | `string`                    | required           |
| `value`          | `string[]`                  | none               |
| `defaultValue`   | `string[]`                  | `[]`               |
| `onValueChange`  | `(value: string[]) => void` | none               |
| `placeholder`    | `string`                    | `"Select options"` |
| `hint`           | `string`                    | none               |
| `size`           | `"sm" \| "md" \| "lg"`      | `"md"`             |
| `supportingText` | `ReactNode`                 | none               |
| `showSearch`     | `boolean`                   | `true`             |
| `showFooter`     | `boolean`                   | `true`             |
| `showTags`       | `boolean`                   | `false`            |
| `disabled`       | `boolean`                   | `false`            |
| `readOnly`       | `boolean`                   | `false`            |
| `invalid`        | `boolean`                   | `false`            |
| `required`       | `boolean`                   | `false`            |
| `name`           | `string`                    | none               |
| `id`             | `string`                    | generated          |
| `className`      | `string`                    | none               |

Pass `value` and `onValueChange` to control the selection, or `defaultValue` to let the field keep its own. `label` names the field for screen readers and is shown above it. `supportingText` appears after the count on the trigger when something is selected. `hint` sits under the field and turns red when `invalid` is set. The footer's Reset keeps any disabled option that was already picked, and Select all skips disabled options.

### MultiSelectOption

| Field         | Type        | Default  |
| ------------- | ----------- | -------- |
| `value`       | `string`    | required |
| `label`       | `string`    | required |
| `description` | `string`    | none     |
| `avatarUrl`   | `string`    | none     |
| `icon`        | `ReactNode` | none     |
| `disabled`    | `boolean`   | `false`  |

An option shows its `avatarUrl` as an avatar with its first letter as the fallback, otherwise its `icon`. `description` is shown in grey after the label.
