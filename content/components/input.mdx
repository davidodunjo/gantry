## Usage

```tsx

```

```tsx
<Input aria-label="Full name" placeholder="Ada Lovelace" />
```

## API Reference

| Prop          | Type                        | Default     |
| ------------- | --------------------------- | ----------- |
| `controlSize` | `"sm" \| "default" \| "lg"` | `"default"` |

`controlSize` sets the height, horizontal padding and text size. `aria-invalid` and `data-invalid` turn the ring red.

All other props pass through to [Base UI's Input](https://base-ui.com/react/components/input).
