
## Usage

```tsx
import { Toggle } from "@/components/ui/toggle"
```

```tsx
<Toggle>Bold</Toggle>
```

A button that stays down. Press it and it holds the pressed background until something presses it again, which is what separates it from an ordinary button.

## Variants

The default toggle is invisible until it is pressed. The outline one carries a border the whole time, so it reads as a control even when it is off.

## API Reference

| Prop              | Type                         | Default     |
| ----------------- | ---------------------------- | ----------- |
| `variant`         | `"default" \| "outline"`     | `"default"` |
| `size`            | `"sm" \| "default" \| "lg"`  | `"default"` |
| `defaultPressed`  | `boolean`                    | `false`     |
| `pressed`         | `boolean`                    | -           |
| `onPressedChange` | `(pressed: boolean) => void` | -           |

Use `pressed` with `onPressedChange` to control the toggle. Set `data-icon="inline-start"` or `data-icon="inline-end"` on an icon inside to tighten the padding on that side.

All other props pass through to [Base UI's Toggle](https://base-ui.com/react/components/toggle).
