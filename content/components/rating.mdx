## Usage

```tsx
import { RatingStars } from "@/components/ui/rating-stars"

```

```tsx
<RatingStars rating={4.5} />
```

## API Reference

### RatingStars

| Prop            | Type     | Default |
| --------------- | -------- | ------- |
| `rating`        | `number` | `5`     |
| `stars`         | `number` | `5`     |
| `starClassName` | `string` |         |

`rating` is clamped between 0 and `stars`. `stars` must be a whole number from 1 to 100, otherwise a `RangeError` is thrown. A visually hidden label reads out the value to screen readers. All other props pass through to the wrapping `div`.

### StarIcon

| Prop       | Type     | Default |
| ---------- | -------- | ------- |
| `progress` | `number` | `100`   |

`progress` is the percentage of the star that is filled, clamped between 0 and 100. All other props pass through to the `svg`.

### RatingBadge

| Prop       | Type                | Default              |
| ---------- | ------------------- | -------------------- |
| `title`    | `string`            | `"Best Design Tool"` |
| `subtitle` | `string`            | `"2,000+ reviews"`   |
| `rating`   | `number`            | `5`                  |
| `theme`    | `"light" \| "dark"` | `"dark"`             |

The `light` theme draws the wreath and text in white, for dark backgrounds. All other props pass through to the wrapping `div`. `Wreath` is also exported if you want the laurel on its own.
