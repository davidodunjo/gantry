## Installation

```bash
bunx shadcn@latest add @gantry/radio-group
```

## Usage

```tsx
import { RadioGroup, RadioGroupItem } from "@/components/ui/radio-group"
```

```tsx
<RadioGroup aria-label="Seat" defaultValue="aisle">
  <RadioGroupItem value="window" aria-label="Window" />
  <RadioGroupItem value="aisle" aria-label="Aisle" />
</RadioGroup>
```

## API Reference

### RadioGroup

| Prop   | Type           | Default |
| ------ | -------------- | ------- |
| `size` | `"sm" \| "md"` | `"sm"`  |

`size` sets the dot and circle size for every item inside the group. `aria-invalid` and `data-invalid` on the group turn all its items red.

All other props pass through to [Base UI's Radio Group](https://base-ui.com/react/components/radio-group).

### RadioGroupItem

| Prop   | Type           | Default                   |
| ------ | -------------- | ------------------------- |
| `size` | `"sm" \| "md"` | the size set on the group |

All other props, including `value` and `disabled`, pass through to [Base UI's Radio](https://base-ui.com/react/components/radio).
