## Installation

```bash
bunx shadcn@latest add @gantry/native-select
```

## Usage

```tsx
import {
  NativeSelect,
  NativeSelectOptGroup,
  NativeSelectOption,
} from "@/components/ui/native-select"
```

```tsx
<NativeSelect aria-label="Assign to" defaultValue="design">
  <NativeSelectOption value="design">Design</NativeSelectOption>
  <NativeSelectOption value="engineering">Engineering</NativeSelectOption>
  <NativeSelectOption value="support">Support</NativeSelectOption>
</NativeSelect>
```

The browser's own select, restyled. Opening it hands over to the platform menu, which is why it fits touch and long option lists so well.

## Sizes

Three heights: 36, 40 and 44 pixels. The chevron grows with the large size; the small size drops to the smaller text size.

## API Reference

### NativeSelect

| Prop   | Type                        | Default     |
| ------ | --------------------------- | ----------- |
| `size` | `"sm" \| "default" \| "lg"` | `"default"` |

`className` styles the wrapper around the select and the chevron. All other props, including `value`, `defaultValue` and `onChange`, pass through to the native `select` element.

### NativeSelectOption and NativeSelectOptGroup

Each takes the props of its native element, `option` or `optgroup`, and sets the colours the platform menu uses for its rows.
