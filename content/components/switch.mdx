## Basic

A switch is a setting, not an answer to a question. Flip it and the change has already happened, so the text below it moves at the same time.

## API Reference

| Prop   | Type                        | Default |
| ------ | --------------------------- | ------- |
| `size` | `"sm" \| "md" \| "default"` | `"sm"`  |
| `slim` | `boolean`                   | `false` |

`size` sets the track to 36 by 20 pixels (`"sm"`) or 44 by 24 (`"md"`). `"default"` is an alias for `"md"`. `slim` removes the padding around the thumb and thins the track. `aria-invalid` and `data-invalid` add a red outline.

All other props pass through to [Base UI's Switch](https://base-ui.com/react/components/switch).
