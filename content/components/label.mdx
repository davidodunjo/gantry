```bash
bunx --bun shadcn@latest add davidodunjo/gantry/label
```

## Usage

```tsx
import { Label } from "@/components/ui/label"
```

```tsx
<Label htmlFor="name">Display name</Label>
```

## Basic

Names the control below it. Because it points at that control, clicking the word puts the caret in the box.

## Required

The required prop adds an asterisk after the text. It is hidden from screen readers, which hear the requirement from the control itself.

<ComponentPreview name="label-required" />

## Invalid

Marking the label invalid turns that asterisk red, so the label agrees with the error underneath instead of sitting apart from it.

<ComponentPreview name="label-invalid" />

## Disabled

A disabled label fades to match its control and refuses the pointer, so clicking the word no longer tries to focus anything.

## API Reference

| Prop       | Type      | Default     |
| ---------- | --------- | ----------- |
| `required` | `boolean` | `undefined` |
| `invalid`  | `boolean` | `undefined` |
| `disabled` | `boolean` | `undefined` |

`required` shows the asterisk. `invalid` turns it red. `disabled` fades the label and shows a not-allowed cursor. Leave a prop unset and the label reads it from the nearest ancestor with the `group` class and a matching `data-required`, `data-invalid` or `data-disabled` attribute. A label that follows a disabled `peer` control fades on its own.

All other props pass through to the native `<label>` element.
