## Installation

```bash
bunx shadcn@latest add davidodunjo/gantry/table
```

## Usage

```tsx
import {
  Table,
  TableBody,
  TableCaption,
  TableCell,
  TableFooter,
  TableHead,
  TableHeader,
  TableRow,
} from "@/components/ui/table"
```

```tsx
<Table>
  <TableHeader>
    <TableRow>
      <TableHead>Invoice</TableHead>
      <TableHead className="text-end">Amount</TableHead>
    </TableRow>
  </TableHeader>
  <TableBody>
    <TableRow>
      <TableCell>INV-2041</TableCell>
      <TableCell className="text-end">£1,240.00</TableCell>
    </TableRow>
  </TableBody>
</Table>
```

A header row, a body and a footer for the total. Long customer names cut off with an ellipsis, and amounts align on the right so the digits line up.

## API Reference

### Table

| Prop   | Type           | Default |
| ------ | -------------- | ------- |
| `size` | `"sm" \| "md"` | `"md"`  |

`size` sets the row and header heights and the side padding for every row beneath it. The `table` element sits inside a `div` that scrolls horizontally, and all other props go to the `table`.

### TableHeader, TableBody, TableFooter, TableRow, TableHead, TableCell and TableCaption

These add no props of their own. They render a `thead`, `tbody`, `tfoot`, `tr`, `th`, `td` and `caption`. A row with `data-state="selected"` takes the selected fill.
