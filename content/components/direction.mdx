## Installation

```bash
bunx shadcn@latest add @gantry/direction
```

## Usage

```tsx
import { DirectionProvider, useDirection } from "@/components/ui/direction"
```

```tsx
<DirectionProvider direction="rtl">
  <div dir="rtl">{children}</div>
</DirectionProvider>
```

The provider changes how components behave, such as which way a slider fills and what the arrow keys do. The `dir` attribute on a wrapper flips the layout. A page that reads right to left needs both.

`useDirection` returns the direction of the nearest provider, so your own components can adapt to it.

## Both directions

The same slider under each direction. Right to left, the fill grows from the right edge and the arrow keys swap, so Left raises the value. The provider changes the behaviour; the dir attribute on the wrapper flips the layout, and a page needs both.

## API Reference

### DirectionProvider

| Prop        | Type             | Default |
| ----------- | ---------------- | ------- |
| `direction` | `"ltr" \| "rtl"` | `"ltr"` |

### useDirection

Returns `"ltr"` or `"rtl"`.

Both are re-exports from [Base UI's DirectionProvider](https://base-ui.com/react/utils/direction-provider).
