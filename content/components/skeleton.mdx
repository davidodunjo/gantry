## API Reference

### Skeleton

`Skeleton` accepts the props of a `div` and adds none of its own. Give it a height, a width and, when the real element is round, a radius through `className`. It pulses until the user prefers reduced motion, then holds still.

Skeleton is not announced to assistive technology. Mark the surrounding region with `aria-busy="true"` and a label, as the examples do.
