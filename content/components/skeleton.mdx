## Installation

```bash
bunx shadcn@latest add @gantry/skeleton
```

## Usage

```tsx
import { Skeleton } from "@/components/ui/skeleton"
```

```tsx
<Skeleton className="h-4 w-48" />
```

The preview above is a profile: a circular skeleton stands in for the avatar and two bars for the name and subtitle, sized to match what lands once the profile loads.

## API Reference

### Skeleton

`Skeleton` accepts the props of a `div`. Give it a height, a width and, when the real element is round, a radius through `className`.

| Prop        | Type                   | Default     |
| ----------- | ---------------------- | ----------- |
| `animation` | `"shimmer" \| "pulse"` | `"shimmer"` |

Both animations stop when the user prefers reduced motion. The shimmer uses the `animate-in` and `slide-in-from-*` utilities from `tw-animate-css`, which `shadcn init` already imports into your CSS.

Skeleton is not announced to assistive technology. Mark the surrounding region with `aria-busy="true"` and a label, as the examples do.
