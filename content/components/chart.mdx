## Usage

Wrap a Recharts chart in `ChartContainer` and pass it a config that names each series. The config sets the label and colour for each series, and the tooltip and legend read their labels from it.

```tsx
import {
  type ChartConfig,
  ChartContainer,
  ChartTooltip,
  ChartTooltipContent,
} from "@/components/ui/chart"
```

```tsx
const chartConfig: ChartConfig = {
  signups: { label: "Signups", color: "var(--chart-1)" },
}

<ChartContainer config={chartConfig}>
  <BarChart data={data}>
    <ChartTooltip content={<ChartTooltipContent />} />
    <Bar dataKey="signups" fill="var(--color-signups)" />
  </BarChart>
</ChartContainer>
```

## API Reference

### ChartContainer

| Prop               | Type                                | Default                       |
| ------------------ | ----------------------------------- | ----------------------------- |
| `config`           | `ChartConfig`                       | required                      |
| `id`               | `string`                            | `useId()`                     |
| `initialDimension` | `{ width: number; height: number }` | `{ width: 320, height: 200 }` |

`config` maps each series key to a `label`, an optional `icon`, and either a `color` or a `theme` with `light` and `dark` colours. `initialDimension` is the size the chart renders at before its container has been measured. Every other prop passes through to the root `div`, and the chart itself is a Recharts `ResponsiveContainer`.

### ChartTooltipContent

| Prop             | Type                            | Default     |
| ---------------- | ------------------------------- | ----------- |
| `indicator`      | `"dot" \| "line" \| "dashed"`   | `"dot"`     |
| `hideLabel`      | `boolean`                       | `false`     |
| `hideIndicator`  | `boolean`                       | `false`     |
| `labelKey`       | `string`                        | `undefined` |
| `nameKey`        | `string`                        | `undefined` |
| `labelFormatter` | `(label, payload) => ReactNode` | `undefined` |

Pass it as `content` to `ChartTooltip`. It takes the Recharts tooltip props, so `formatter` and `labelFormatter` work as they do on Recharts.

### ChartLegendContent

| Prop            | Type                | Default     |
| --------------- | ------------------- | ----------- |
| `hideIcon`      | `boolean`           | `false`     |
| `nameKey`       | `string`            | `undefined` |
| `verticalAlign` | `"top" \| "bottom"` | `"bottom"`  |

Pass it as `content` to `ChartLegend`. Every other prop passes through to the Recharts legend payload.
