## Installation

```bash
bunx shadcn@latest add davidodunjo/gantry/tabs
```

## Usage

```tsx
import { Tabs, TabsContent, TabsList, TabsTrigger } from "@/components/ui/tabs"
```

```tsx
<Tabs defaultValue="overview">
  <TabsList>
    <TabsTrigger value="overview">Overview</TabsTrigger>
    <TabsTrigger value="team">Team</TabsTrigger>
  </TabsList>
  <TabsContent value="overview">Your workspace overview.</TabsContent>
  <TabsContent value="team">Manage the people on your team.</TabsContent>
</Tabs>
```

The default style: the active tab floats on a filled pill inside a padded track.

## API Reference

### TabsList

| Prop      | Type                                         | Default     |
| --------- | -------------------------------------------- | ----------- |
| `variant` | `"default" \| "line" \| "gray" \| "minimal"` | `"default"` |
| `size`    | `"sm" \| "md"`                               | `"sm"`      |

### Tabs

| Prop          | Type                         | Default        |
| ------------- | ---------------------------- | -------------- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |

`Tabs`, `TabsTrigger` and `TabsContent` pass their props straight through to [Base UI's Tabs](https://base-ui.com/react/components/tabs): use `defaultValue`, or `value` with `onValueChange`, on `Tabs`, and a matching `value` on each trigger and panel. `tabsListVariants` exposes the list's classes for reuse.
