## API Reference

| Prop    | Type                                                                        | Default   |
| ------- | --------------------------------------------------------------------------- | --------- |
| `icon`  | `ReactNode`                                                                 | -         |
| `size`  | `"sm" \| "md" \| "lg" \| "xl"`                                              | `"sm"`    |
| `color` | `"brand" \| "gray" \| "error" \| "warning" \| "success"`                    | `"brand"` |
| `theme` | `"light" \| "gradient" \| "dark" \| "outline" \| "modern" \| "modern-neue"` | `"light"` |

The icon can be passed as `icon` or as `children`, and `icon` wins when both are set. Pass `title` to name the icon for assistive technology when it carries meaning; the icon inside should be marked `aria-hidden`. The `outline` and `gradient` themes draw rings around the frame, which extend past its box. All other props pass through to the `div`.
