## API Reference

### Illustration

| Prop                | Type                                               | Default             |
| ------------------- | -------------------------------------------------- | ------------------- |
| `type`              | `"box" \| "cloud" \| "credit-card" \| "documents"` | Required            |
| `size`              | `"sm" \| "md" \| "lg"`                             | `"lg"`              |
| `svgClassName`      | `string`                                           | —                   |
| `childrenClassName` | `string`                                           | —                   |
| `children`          | `ReactNode`                                        | Shape-specific icon |

`svgClassName` styles the decorative SVG. `childrenClassName` styles the center icon frame. Pass your own icon as `children`, or `null` to hide the frame.

### Individual shapes

`BoxIllustration`, `CloudIllustration`, `CreditCardIllustration` and `DocumentsIllustration` are also exported from `@/components/ui/illustration`, or from their individual `illustration-box`, `illustration-cloud`, `illustration-credit-card` and `illustration-documents` files. They accept the same props except `type`.

| Component                | Default `children` |
| ------------------------ | ------------------ |
| `BoxIllustration`        | `UploadCloud02`    |
| `CloudIllustration`      | `SearchLg`         |
| `CreditCardIllustration` | `AlertCircle`      |
| `DocumentsIllustration`  | `UploadCloud02`    |

All other props, including `className`, pass through to the outer `div`. The decorative SVG is hidden from assistive technology.
